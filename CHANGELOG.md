  per script and declaring the root smooth-scroll contract; added a subtle
  full-width semantic footer surface and restored native scrolling to the
  sticky desktop documentation navigation.
- Centered the Flowstack layer story on one editorial axis, normalized layer
  icon treatment, replaced status badges with consistent contextual actions,

  added an explicit Atom-derived Apple touch icon.

  rounded frame, scrollable Tabs and Accordion rows use unclipped inset rings,

  compact mobile Tabs now visually hide rather than remove their text labels.
- Matched the FAQ trigger radius to its clipped Accordion surface, carried the
  CodeBlock radius onto its focusable scroll viewport, and refined the mobile
  navigation with a square close target, centered icon/copy pairs, and a
  centered footer composition.
- Added deliberate spacing to the 404 recovery actions, fully reset the mobile
  Drawer Footer's inherited flex alignment when composing it as a grid, and

- Replaced the overlapping Docs navigation with mutually exclusive Guides,

- Moved the six public Utilities into the Primitives reference experience,
  categorized all 70 subpaths in searched Accordion rail groups with visible

  height, retained category Badges on every card, and corrected Public Catalog

- Moved each primitive card's category Badge into its top-right action slot;
  added semantic Feature Signals to all 70 public subpaths; and introduced a
  bright, application-styled live Atom behavior canvas with route-specific
  specimens, truthful interaction signals, and seven lazy category chunks.
- Added complete 70-route specimen crawling, representative cross-family
  interaction tests, two-appearance category Axe coverage, and mobile canvas

  Menu portal ownership, Data Grid selection configuration, and the Image

- Raised primitive-rail link typography to the established documentation floor,
  removed the disconnected rounded open-trigger fill, and normalized native

- Added focused, repository, and release verification tiers, repository-owned

  nightly clean-run qualification.
- Increased light-theme secondary-text contrast and made horizontally
  scrollable Markdown code and table regions keyboard-focusable.
- Kept the visible Atom version in the header brand's accessible link name so
  experimental label-content validation agrees with the rendered identity.
- Simplified every primitive Feature Signals list into consistent compact
  prose cards with natural inline code; corrected duplicated required markers;

  Pagination, Sidebar, Toolbar, Toast, Swipeable Item, Tree, Tree Grid,
  Accordion, Collapsible, Divider, Progress, Hooks, Direction, and Visually
  Hidden specimens around their documented Atom state and interaction
  contracts. Added production regressions for state changes, expansion,

- Contained Sidebar active treatment inside its collapsed rail, corrected the
