# Atom Website Theme Fixture

`atom-website.theme.json` is the application-owned source for the Atom
documentation website's system-default dual appearance. Generated browser and
machine artifacts live under `src/app/theme/generated/` and are never edited
directly.

During pre-release qualification, `brick-theme-contract.json` retains the exact
contract generated by `@flowstack-ui/brick` commit
`215560b8e14c1bd06cafc91826ae9468029f431b`. Registry Brick `0.1.6` predates
the packaged contract even though that development commit still reports the
same package version. Remove this snapshot and compile against
`node_modules/@flowstack-ui/brick/dist/theme-contract.json` after the next
coordinated Brick release exposes it.

Regenerate and verify with:

```bash
npm run theme:compile
npm run theme:check
```

The compiler is a development dependency pinned to a full immutable Theme Git
commit. Production imports only generated CSS. Appearance persistence,
pre-paint selection, layout, gradients, specimen styling, and responsive
component geometry remain application-owned.
